## Open-source projects

### [TruFlint](https://github.com/devhuzi/truflint)
A self-hosted money app for personal, job, side-business and savings accounts. Installable web app on Supabase, with an optional bring-your-own-key AI assistant that proposes changes and waits for your confirmation; every AI write lands in an audit log. Row-level security on every table, with two-tenant isolation tests.

`TypeScript` `Expo / React Native Web` `Supabase` `Postgres + RLS` `Vitest` `Docker`

### [AI Video Production Hub](https://github.com/devhuzi/ai-video-hub)
Turns prompt packs or narration scripts into finished short-form videos by chaining AI image models, AI video models (Veo 3.1, Grok) and FFmpeg. The job queue can pause, resume, cancel and partially re-run; image generation falls back SnapGen → Kie.ai → fal.ai so a failed provider doesn't kill the run.

`Python` `FastAPI` `React` `FFmpeg` `Docker`

### [Tools & Subs Manager](https://github.com/devhuzi/subs-manager)
Tracks the software, subscriptions and one-time purchases you pay for. Runs as a local-first desktop app (Windows, macOS) and as a self-hostable PWA, from the same code, with renewal reminders that arrive even when the app is closed.

`TypeScript` `React` `Electron` `Supabase` `Vitest` `Playwright`
